# Security policy

This is a personal portfolio project, not a live service with real users. I still want to hear about security problems in it.

## Reporting a vulnerability

Please use GitHub's private reporting: open the **Security** tab of this repo and click **Report a vulnerability**. Please don't open a public issue for security problems.

I'll try to reply within a week.

## Scope

- Code and configuration in this repository
- Out of scope: denial-of-service testing against any deployed demo

There is no bug bounty.
